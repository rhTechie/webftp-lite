# FTP Web 工具

一个基于Web的FTP客户端工具，无需安装任何软件，通过浏览器即可管理FTP服务器上的文件。

## ✨ 特性

- 🌐 **纯网页操作**：无需安装客户端软件，打开浏览器即可使用
- 📱 **跨平台支持**：支持电脑、手机、平板等任何有浏览器的设备
- 🔄 **自动重连**：FTP连接断开时自动重连，无需手动操作
- 📁 **完整功能**：支持浏览、上传、下载、删除、重命名、创建文件夹等操作
- 🎨 **现代化界面**：简洁美观的用户界面，操作直观
- 🚀 **轻量快速**：基于Node.js，部署简单，运行高效

## 📋 功能列表

- ✅ 连接FTP服务器
- ✅ 浏览目录和文件
- ✅ 上传文件（支持多文件上传）
- ✅ 下载文件
- ✅ 删除文件和文件夹
- ✅ 创建新文件夹
- ✅ 路径跳转
- ✅ 返回上级目录

## 🛠️ 技术栈

- **后端**：Node.js + Express + WebSocket
- **前端**：原生HTML + CSS + JavaScript
- **FTP库**：basic-ftp

## 📦 安装部署

### 环境要求

- Node.js 14.0 或更高版本
- npm 或 yarn

### 安装步骤

1. **克隆或下载项目**

```bash
cd /path/to/ftp
```

2. **安装依赖**

```bash
npm install
```

3. **启动服务器**

```bash
npm start
# 或者
node server.js
```

4. **访问工具**

服务器启动后，会显示访问地址：

```
FTP Web Tool 运行在: http://0.0.0.0:3000
局域网访问: http://<你的IP>:3000
```

在浏览器中打开显示的地址即可使用。

## 🚀 使用方法

### 1. 连接FTP服务器

打开网页后，填写以下信息：

- **服务器地址**：FTP服务器的IP或域名（例如：ftp.example.com）
- **端口**：默认为21
- **用户名**：FTP账号用户名（默认：root）
- **密码**：FTP账号密码（默认：root）

点击"连接"按钮即可连接到FTP服务器。

### 2. 浏览文件

连接成功后，会自动显示根目录的文件列表。

- 📁 **文件夹图标**：点击可进入该目录
- 📄 **文件图标**：显示文件信息
- ⬆️ **返回上级**：点击可返回上级目录

### 3. 上传文件

1. 点击工具栏的"📤 上传"按钮
2. 在弹出的对话框中选择要上传的文件（支持多选）
3. 点击"上传"按钮
4. 等待上传完成，文件列表会自动刷新

### 4. 下载文件

点击文件右侧的"下载"按钮，文件会自动下载到浏览器的默认下载目录。

### 5. 删除文件/文件夹

点击文件或文件夹右侧的"删除"按钮，确认后即可删除。

⚠️ **注意**：删除操作不可恢复，请谨慎操作。

### 6. 创建文件夹

1. 点击工具栏的"📁 新建文件夹"按钮
2. 输入文件夹名称
3. 点击"创建"按钮

### 7. 路径跳转

在工具栏的"当前路径"输入框中：

1. 直接编辑路径（例如：/home/user/documents）
2. 点击"跳转"按钮
3. 即可快速跳转到指定目录

### 8. 刷新列表

点击工具栏的"🔄 刷新"按钮，可以刷新当前目录的文件列表。

### 9. 断开连接

点击工具栏的"断开连接"按钮，可以断开与FTP服务器的连接，返回登录页面。

## 🌐 局域网访问

### 在同一局域网内的其他设备访问

1. **获取服务器IP地址**

```bash
# Linux/Mac
hostname -I | awk '{print $1}'

# Windows
ipconfig
```

2. **在其他设备上访问**

在同一WiFi下的手机、平板或其他电脑的浏览器中输入：

```
http://服务器IP:3000
```

例如：`http://192.168.1.100:3000`

⚠️ **注意**：本工具仅支持局域网内使用，不建议暴露到公网环境。

1. **仅限局域网使用**：本工具设计用于局域网环境，请勿暴露到公网
2. **使用强密码**：FTP账号使用强密码

## 🐛 常见问题

### 1. 连接失败

- 检查FTP服务器地址、端口、用户名、密码是否正确
- 确认FTP服务器是否正常运行
- 检查网络连接是否正常
- 确认防火墙是否允许FTP端口（默认21）

### 2. 连接断开

FTP服务器通常有空闲超时设置（1-5分钟），本工具已实现自动重连功能，下次操作时会自动重连。

### 3. 上传失败

- 检查文件大小是否超过FTP服务器限制
- 确认是否有写入权限
- 检查磁盘空间是否充足

### 4. 无法访问（其他设备）

- 确认设备在同一局域网内
- 检查服务器防火墙是否开放3000端口
- 尝试使用服务器IP而不是localhost

### 5. 停止服务器

```bash
# 查找进程
ps aux | grep "node server.js"

# 停止进程
pkill -f "node server.js"
```
